현업 요구사항을 정리하고 데이터·화면 흐름을 설계한 뒤 구현과 검증을 반복합니다. 개인 앱과 BGNT 시스템 개발에는 ChatGPT/Codex를 활용했습니다. 업무 소스는 비공개 저장소에서 관리하고, 공개 포트폴리오에는 담당 역할과 구현 사례를 정리했습니다.
